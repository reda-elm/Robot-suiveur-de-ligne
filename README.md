# Robot-suiveur-de-ligne
Conception d'un robot autonome capable de suivre une ligne noire avec fluidité. L'implémentation d'un contrôleur PID ajuste sa trajectoire en temps réel. Ce projet couvre l'intégration complète d'un système embarqué : assemblage matériel (câblage, sertissage) et programmation de l'algorithme.
